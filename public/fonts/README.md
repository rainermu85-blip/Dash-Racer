# Gravity Pixel

Creator: John Watson (Jotson)

Requested font page: https://jotson.itch.io/gravity-pixel-font

Original font files obtained from the creator's public repository:
https://github.com/jotson/gravity_obs/tree/04eaaf70d7a34ef8f058d85cbddce9d4b6efae2d

- `GravityRegular5.ttf`: regular text, CSS weight 400.
- `GravityBold8.ttf`: primary HUD values and bold text, CSS weight 700.

The files retain their original font metadata and glyphs. `Gravity-LICENSE.txt`
is the MIT license included with that repository. Both fonts are embedded as data URLs in `index.html`; no font-file HTTP request
is needed. The original TTFs remain here as the source files. This works in
both a direct repository publish and a Vite build under the Pages base path.
